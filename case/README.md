# case

Parametric sources for the tray and switch plates, MX first, with 42-key and 36-key variants.

- Sources: parametric CAD files, driven by the board outline and switch positions exported from `pcb/`.
- Exports: printable STL files, one set per variant and switch type (MX or Choc). The right half is mirrored in the slicer, not exported separately.
